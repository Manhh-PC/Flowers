# Ảnh thử cá nhân

Đặt ảnh bạn muốn thử vào thư mục này, rồi điền `MY_IMAGE = "demo_images/ten_anh.jpg"`
trong ô demo tùy chọn của notebook. Ảnh cá nhân được `.gitignore` loại khỏi GitHub.

Mô hình chỉ có 102 lớp hoa và không phát hiện mọi ảnh ngoài tập lớp. Điểm dự đoán
chưa được hiệu chỉnh, không phải cam kết mô hình nhận dạng đúng ảnh mới.
