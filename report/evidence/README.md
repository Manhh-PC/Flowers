# Minh chứng chọn lọc đưa vào báo cáo/GitHub

Sau một lần chạy thật, chép các hình PNG/PDF và bảng CSV cần nộp từ
`outputs/<ma-lan-chay>/` vào thư mục này. Giữ cấu hình, nguồn và chú thích hình
để biết chúng đến từ lần chạy nào. Không chép ảnh gốc, model lớn, cache hoặc
môi trường Python vào đây.

Thư mục này được đưa vào Git, khác với `outputs/` của từng lần chạy.
Chỉ dùng số liệu thực tế, không dùng kết quả thử mã bằng dữ liệu giả.
